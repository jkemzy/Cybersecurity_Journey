# Windows Fundamentals 2

## Overview

This room focused on Windows security features and how they help protect users and systems.

---

# User Account Control (UAC)

UAC helps prevent unauthorized changes by prompting for administrator approval before certain actions are performed.

---

# Windows Defender

Built-in antivirus that provides:

- Malware detection
- Real-time protection
- Virus scanning

---

# Windows Firewall

Filters incoming and outgoing network traffic.

Profiles

- Domain
- Private
- Public

---

# BitLocker

Encrypts entire drives to protect data if a device is lost or stolen.

---

# Event Viewer

Open

```
eventvwr.msc
```

Logs

- Application
- Security
- System
- Setup

Useful for troubleshooting and security investigations.

---

# NTFS Permissions

Permissions include:

- Read
- Write
- Modify
- Execute
- Full Control

---

# Authentication vs Authorization

Authentication verifies identity.

Authorization determines what a user is allowed to access after authentication.

---

# Windows Updates

Keeping Windows updated helps fix vulnerabilities and improve stability.

---

# Key Takeaways

- UAC helps protect system integrity.
- Defender provides built-in malware protection.
- Firewall controls network access.
- Event Viewer records important system and security events.
- BitLocker protects data through encryption.

---

# Skills Gained

- Understanding Windows security
- Reviewing event logs
- Managing permissions
- Learning built-in defensive tools
